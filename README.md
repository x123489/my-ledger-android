# 我的记账本（安卓原生 App 版）

一个**真正的安卓 App**：数据直接存在你手机的文件夹里（不再是浏览器内部），可装到桌面、可离线与手动云同步无关。功能完整复刻网页版：收支分类记账、明细（搜索/修改/删除/排序）、统计与分析（饼图/排行/月度趋势/分类月度对比/数据洞察/预算）、导入导出 CSV、备份恢复（换手机迁移）、**负数冲销**。

## 一、数据存在哪里（重点）
- 日常数据：`手机存储/Android/data/com.example.myledger/files/ledger_data.json`
  —— 这是手机里一个**真实可见的文件夹**，文件管理器就能看到，不依赖任何服务器。
- 备份 / 导出 / 模板：自动放进手机「下载 / Ledger」文件夹，方便你查看和搬运。
- 换手机：旧手机点「备份到下载文件夹」→ 把文件发到新手机 → 新手机点「从备份恢复」即可。

## 二、怎么拿到安装包（apk）
当前电脑没有安卓编译工具，所以用 **GitHub 免费云编译** 一键出包，你无需装任何开发工具。

### 方案 A：GitHub 云编译（推荐，零安装）
1. 注册一个免费 GitHub 账号：https://github.com （用邮箱即可）。
2. 新建一个仓库（Repository），名字随便，例如 `my-ledger-android`，选 **Public** 或 **Private** 都行。
3. 把本目录下的**全部文件**上传到这个仓库（可直接把文件夹拖进 GitHub 网页的上传区，或用 GitHub Desktop）。
4. 在仓库里点 **Actions** 标签 → 看到名为 **Build APK** 的工作流 → 点 **Run workflow**（或推送代码后自动运行）。
5. 等几分钟，运行完成后点该次运行 → 右侧 **Artifacts** → 下载 `myledger-apk`（里面是 `app-debug.apk`）。
6. 把 `app-debug.apk` 传到手机，点击安装（首次需允许「安装未知来源应用」）。

### 方案 B：本地用 Android Studio（如果你有电脑）
1. 电脑装 Android Studio（免费）：https://developer.android.com/studio
2. 打开本目录（Open → 选择 `ledger-app-android` 文件夹）。
3. 等它同步完（会联网下载依赖），点菜单 **Build → Build Bundle(s) / APK(s) → Build APK(s)**。
4. 编译完在 `app/build/outputs/apk/debug/` 得到 `app-debug.apk`，传到手机安装。

## 三、功能一览
- 记账：收/支切换、分类、金额（**可填负数冲销**）、日期、备注、标签。
- 明细：按月查看、跨月搜索、5 种排序、✏️ 修改、🗑️ 删除。
- 统计：本月/近3月/本年/全部；收支构成（饼图+排行）；月度收支趋势；数据小洞察（最大单笔、最高分类、环比）；分类月度对比；预算进度与超支提醒。
- 我的：预算设置、备份到下载文件夹、从备份恢复（覆盖/合并）、下载 CSV 模板、导入 CSV、导出全部 CSV、清空。

## 四、技术说明（给想改的人）
- 纯 Kotlin + Jetpack Compose，无第三方图表库（图表用 Canvas 手绘）。
- 存储：`org.json` 写文件，备份/导出走 MediaStore（API 29+）或旧版下载目录。
- 编译：AGP 8.5.2 + Kotlin 1.9.24 + Compose Compiler 1.5.14 + Compose BOM 2024.06.00。
- 最低支持 Android 7.0（API 24）。

## 五、已知小限制
- 日期校验只认格式 `YYYY-MM-DD`，不校验日历合法性（如 `2026-13-40` 会被收下，日常使用基本碰不到）。
- 本工程在当前开发机未做真机/模拟器运行验证（无安卓 SDK），依赖 GitHub Actions 云编译；若编译报红，通常是版本或 API 小差异，按报错微调即可。
